# Ada Malef Diary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Provide a runnable calendar diary with persistent CRUD and an internal editor.

**Architecture:** Alire workspace packages enforce inward dependencies: storage imports application ports, and application imports domain. The executable composes storage and Malef adapters.

**Tech Stack:** Ada 2022, Alire, GNAT, GPRbuild, pinned Malef.

**Spec:** `docs/superpowers/specs/2026-11-18-diary-design.md`

## Global Constraints

- One entry per date; local UTF-8 files; no source comments.
- No framework or concrete I/O dependencies in domain/application.
- Implementation choices delegated by user; execute in the provided directory without additional approval or automatic commits.

## Review Focus

- Leap years, month-end navigation, and supported date boundaries.
- Unicode, empty/blank titles, newlines, control characters, and long drafts.
- Failed writes preserve previous data and the current draft.
- Cancel/delete confirmations and small terminal resizing.
- Restart persistence, duplicate creation, and concurrent access.
